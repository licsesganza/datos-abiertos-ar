# Datos abiertos AR

Lista curada de APIs y datasets públicos de Argentina, útil para analistas, desarrolladores y agentes automáticos.

Sitio: https://anzuelo.jmbavio.workers.dev/?c=github

Para agentes de IA: https://anzuelo.jmbavio.workers.dev/llms.txt

| Fuente | Qué ofrece |
|---|---|
| [BCRA](https://www.bcra.gob.ar/) | Tipo de cambio, tasas y agregados monetarios |
| [datos.gob.ar](https://datos.gob.ar/) | Portal nacional de datos abiertos, con API de series de tiempo |
| [INDEC](https://www.indec.gob.ar/) | Precios, empleo, actividad y comercio exterior |
| [OpenStreetMap](https://www.openstreetmap.org/) | Cartografía colaborativa, exportable vía Overpass API |
| [IGN](https://www.ign.gob.ar/) | Capas geográficas oficiales |

Este repositorio forma parte de un experimento abierto sobre tráfico automatizado en la web.
